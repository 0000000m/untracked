## 1.0.0 — 2026-11-24

Initial source release prepared for review.

- Two static Manifest V3 DNR rules remove 35 named tracking parameters and domain-scoped YouTube sharing IDs before eligible requests are sent.
- HTTP(S) GET/HEAD cleanup preserves unrelated parameters, encoding, fragments and non-GET/HEAD request bodies.
- Portable unpacked installation instructions for Vivaldi on Linux and Chromium on macOS.
- Standard-library HTTP/HTTPS integration tests, permission checks and deterministic ZIP packaging.
- Permission/security review, explicit limitations, MIT licensing and AI-assistance disclosure.

This release is a separately prepared source project. It does not replace an existing locally signed installation automatically.
